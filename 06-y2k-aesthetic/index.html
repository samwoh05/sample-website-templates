Hello

Raised on screensavers and see-through plastic

I grew up taking apart a see-through phone to see how it lit up. I still design that way. Make the inside clear, then make the outside fun.

I work with small teams on apps, kiosks, players and broadcast graphics. I design the screens, animate them and build the prototype in code so we can test the real thing.

Based in
Rotterdam, works remotely
Works with
Product teams, labels, studios, broadcasters
Tools
Figma, After Effects, Rive, HTML and CSS
Off hours
Fixing old portable CD players
